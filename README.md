# RetailPulse-SQL-Analysis
Retail Business Intelligence and Sales Analysis using Oracle SQL

## About the Project

RetailPulse is a SQL-based business intelligence project designed to analyze retail sales data using Oracle SQL.

The project uses five related tables: Customers, Categories, Products, Orders, and Order_Details.

The main objective is to analyze sales performance, customer behavior, product performance, and business trends using SQL queries.

## Tools & Technologies

- Oracle SQL
- SQL*Plus
- GitHub

- ## Database Structure

The project contains five tables:

1. **CUSTOMERS** – Stores customer information.
2. **CATEGORIES** – Stores product category details.
3. **PRODUCTS** – Stores product information, prices, and stock.
4. **ORDERS** – Stores customer order details.
5. **ORDER_DETAILS** – Stores products, quantities, prices, and discounts for each order.


## SQL Analysis

The project includes SQL queries to analyze:

- Total revenue and estimated profit.
- Sales performance and monthly trends.
- Top-selling products.
- Customer purchasing behavior.
- Category-wise and city-wise revenue.
- Order status and payment methods.
- Low-stock products.
- Data quality and consistency.
